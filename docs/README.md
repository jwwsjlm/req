# req 中文 Wiki

这里是 `github.com/jwwsjlm/req/v3` 的中文专题文档。第一次使用这个增强版 req，或者还没有创建过 Go module，请先看 [Go 与 req 零基础入门](00-go-req-beginner.md)；已有经验的读者可从 [Wiki 首页](Home.md) 选择主题，并用 [_Sidebar.md](_Sidebar.md) 作为完整导航。

文档中的代表性代码位于 [examples](examples/README.md)。这些示例不依赖公网，随仓库执行以下命令即可验证：

```sh
go test ./docs/examples
```

公开 API 以当前版本源码和 `go doc github.com/jwwsjlm/req/v3` 为准；文档重点解释选择、边界和生产使用方式，不替代 Go API 文档。
